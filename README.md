# PC 隐私浏览器

极致隐私的 Windows/Mac/Linux 桌面浏览器，基于 Electron 构建。

## 核心特性

### 极致隐私保护

- ✅ **启动时清除**：每次启动自动清除所有残留数据
- ✅ **关闭时清除**：退出时彻底擦除所有痕迹
- ✅ **后台清除**：失去焦点时自动清理（不退出进程）
- ✅ **手动清除**：随时一键清除所有数据

### 反指纹技术

- 🛡️ **Canvas 指纹防护**：返回空白画布，阻止 Canvas 指纹采集
- 🛡️ **WebGL 指纹防护**：伪装为 Intel UHD Graphics 630
- 🛡️ **屏幕指纹防护**：伪装分辨率为 1920×1080
- 🛡️ **硬件指纹防护**：伪装 CPU 核心数、内存大小
- 🛡️ **平台伪装**：伪装为标准 Windows 桌面环境
- 🛡️ **随机 User-Agent**：每次启动随机生成不同的浏览器标识

### 隐私设置

- 🔒 **完全隔离的会话**：使用独立的 `privacy` partition
- 🔒 **禁用缓存**：所有数据仅保存在内存中
- 🔒 **禁用持久化存储**：拒绝 IndexedDB、LocalStorage 等
- 🔒 **禁用 WebRTC**：防止真实 IP 地址泄露
- 🔒 **禁用遥测**：完全阻止所有后台网络请求
- 🔒 **禁用 DNS 预取**：防止提前解析域名暴露浏览意图

## 功能特性

- 📍 **地址栏**：支持 URL 直接访问和 DuckDuckGo 搜索
- 🗂️ **多标签支持**：同时打开多个标签页，独立浏览
- ⭐ **书签功能**：内置 Jiurelay 书签，快速访问
- ⬅️ **前进/后退导航**：自由切换浏览历史
- 🔄 **刷新/停止加载**：控制页面加载状态
- 🗑️ **手动一键清除**：随时清除所有浏览数据
- 🔒 **安全状态提示**：实时显示隐私保护状态
- 🎨 **Safari 风格界面**：简洁优雅的深色主题

## 安装使用

### 开发环境

```bash
# 安装依赖
npm install

# 开发模式（热重载）
npm run dev

# 编译 TypeScript
npm run build

# 启动应用
npm start
```

### 打包发布

```bash
# 构建可执行文件
npm run build

# Windows 打包
electron-builder --win

# macOS 打包
electron-builder --mac

# Linux 打包
electron-builder --linux
```

打包产物在 `build/` 目录下。

## 技术栈

- **Electron** - 跨平台桌面应用框架
- **TypeScript** - 类型安全的 JavaScript
- **原生 WebView** - 基于 Chromium 的浏览器引擎

## 隐私机制

### 启动流程

1. 清除所有残留数据（Cookie、缓存、存储）
2. 创建全新的隔离会话
3. 配置极致隐私设置
4. 注入反指纹脚本
5. 随机化浏览器标识

### 浏览流程

- 所有网络请求都经过隐私过滤
- 自动注入反指纹脚本到每个页面
- 实时阻止各种追踪技术
- 内存中临时存储（不写入磁盘）

### 退出流程

1. 清除所有会话数据
2. 清除所有缓存目录
3. 清除系统剪贴板
4. 清除 DNS 缓存
5. 完全退出进程

## 注意事项

⚠️ **这是一个极致隐私浏览器**：

- 不保存任何浏览历史
- 不保存任何密码
- 不保存任何 Cookie
- 关闭后一切数据消失
- 每次启动都是全新身份

⚠️ **限制**：

- 无法登录需要持久化的网站
- 无法使用需要 WebRTC 的服务（如视频通话）
- 某些网站可能因为反指纹措施无法正常工作
